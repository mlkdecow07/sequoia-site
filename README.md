# Sequoia Christian School Website

A Next.js replica of [sequoiachristian.com](https://sequoiachristian.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/history` — Our History
- `/our-faculty` — Faculty
- `/educationalapproach` — Educational Approach
- `/variabletuition` — Tuition
- `/eitc` — EITC Program
- `/812-2` — Enrollment Process
- `/845-2` — Testimonials
- `/apply` — Application portal
- `/employment` — Employment

## Build

```bash
npm run build
npm start
```
